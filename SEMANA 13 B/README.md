## Descripción

Este proyecto desarrolla una función en Python que calcula el promedio de dos notas.

La función recibe dos parámetros, realiza el cálculo del promedio y devuelve el resultado utilizando la instrucción return.

## Archivo

- promedio_notas.py

## Ejecución

Al ejecutar el programa se muestra en pantalla el promedio de las dos notas ingresadas.

## Pseudocódigo

FUNCION calcularPromedio(nota1, nota2)
    promedio ← (nota1 + nota2) / 2
    RETORNAR promedio
FIN FUNCION

nota1 ← 8
nota2 ← 10

resultado ← calcularPromedio(nota1, nota2)

IMPRIMIR resultado
